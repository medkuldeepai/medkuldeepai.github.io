# Surgical Video Label Propagation

## Overview

A training-free framework for surgical video annotation using frozen self-supervised representations and graph-based transductive learning.

## Methods

- SimCLR
- DINO
- MAE
- kNN
- LLGC

## Results

- mAP up to 0.91
- Strong correlation with Krippendorff's Alpha

## Technologies

- Python
- PyTorch
- Scikit-learn
